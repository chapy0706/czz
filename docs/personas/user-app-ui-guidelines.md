# ユーザー側UIガイド（ペルソナ適用ルール）

- Persona: docs/personas/user-app-primary-user.md

## 画面共通ルール

- 主要CTAは1つに絞る（迷いを作らない）
- “次にやること”を上部（または固定領域）で宣言する
- タップ反応を必ず出す（押下状態・小さなアニメ）
- ローディングはスケルトン優先（spinnerだけは不安を増やす）
- エラーは「原因」より「次にどうすれば良いか」を先に出す

## 文言ルール

- 指摘しない（×「入力が不正です」→ ○「ここをこうするとOKだよ」）
- 叱らない（×「失敗」→ ○「もう一回いこう」）
- 褒める（小成功でも言う）

## マスコット運用ルール

- “邪魔にならない”が最優先（被り・固定位置に注意）
- 状況で表情/セリフが変わる（成功/失敗/迷い/初回）
- 「説明を読ませる役」ではなく「次の行動を短く示す役」
